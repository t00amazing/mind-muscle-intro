10가지 마음의 근육

👆 카드를 눌러보세요

🐱 탐구냥
호기심 조절력
약물을 처음 접하는 주요 계기는 단순한 호기심. 직접 시도하는 대신 확인하는 습관으로 대응
🦁 당당사자
또래 거절력
또래의 권유는 최초 사용의 주된 경로. 관계를 해치지 않으면서 거절하는 힘
🐨 여유코알라
스트레스 해소력
스트레스를 피하려고 약물에 손대는 경우도 많음. 건강한 대체 해소법 확보
🐿️ 똑똑다람쥐
카페인·각성제 절제력
카페인 의존은 심각한 수준. 카페인 없이 맑은 정신을 유지하는 능력
🐶 다정멍멍
가족·신뢰관계 소통력
신뢰관계가 없으면 위험행동이 늘어남. 중독으로 빠지기 전 골든타임을 지키는 능력
🐼 포근판다
수면·컨디션 관리력
수면 부족은 각성제 의존 악순환을 만듦. 건강한 생활 패턴을 유지하는 능력
🐢 꾸준거북
성과압박 대응력
외모·성적 압박은 오남용으로 이어질 수 있음. 빠른 효과보다 건강한 노력을 선택
🐧 똑똑펭귄
미디어 분별력
온라인 속 약물 허위 광고가 넘쳐남. 거짓 정보의 숨은 의미를 판별하는 능력
🦉 지혜부엉
정확한 위험 인지력
왜곡된 정보가 비법처럼 퍼지는 경우가 많음. 소문 대신 사실에 근거해 판단하는 능력
🐰 용기토끼
도움요청력
처벌보다 상담·치료가 회복에 도움이 됨. 숨기지 않고 도움을 요청하는 능력

마음의 근육 연습하기

👆 눌러보면 핵심 내용이 표시돼요

  • 자가진단에서 찾은 내 마음의 근육을 실제 상황에 적용해보는 활동
  • 근육사전에서 가장 강한 근육 1개 선택
  • 상황카드연습에서 이겨낼 수 있는 상황 2개와 흔들리는 상황 2개를 골라 대응법 직접 서술
  • 근육 사용 선언에서 흔들리는 순간의 나에게 짧은 글 남기기
  • 제출 후 친구들 이야기에서 다른 친구들의 대응을 익명으로 확인, 내 활동 보기에서 전체 내용을 발표 화면처럼 정리
  • 정답을 맞히는 활동이 아니므로 완벽하게 쓰지 않아도 되고, 제출 후에도 다시 수정 가능

예시 데이터로 먼저 체험해보기

👆 눌러보면 핵심 내용이 표시돼요

  • 박보건, 김보건, 이보건, 정보건, 최보건 중 원하는 이름 하나를 골라 검색한 뒤 입장
  • 근육사전: 자가진단으로 찾은 나의 가장 강한 근육을 선택하고, 10가지 근육 전체의 특징을 살펴봄
  • 상황카드연습: 이겨낼 수 있는 상황 2개, 흔들릴 수 있는 상황 2개를 골라 직접 대응법을 써보는 활동
    10가지 상황: 전자담배 권유, 음주 권유, 숏폼 콘텐츠 과몰입, 고카페인 음료 과다 섭취, ADHD 약물 공유, 미인증 보조제 광고, 불안 회피용 미디어 의존, SNS 반응 과몰입, 심야 게임 과몰입, 마약류에 대한 왜곡된 인식
  • 근육사용선언: 흔들리는 순간의 나에게 편지를 쓰고 편지지나 포스트잇 이미지로 저장
  • 친구들이야기: 같은 상황에서 다른 예시 학생들은 어떤 근육을 썼는지 익명으로 확인
  • 내활동보기: 제출한 내용을 발표 화면처럼 정리해서 확인

우리 반에 가져가는 방법

코딩 지식 없이, 구글 계정만 있으면 그대로 가져다 쓸 수 있어요. 아래 순서대로 진행하시면 돼요. (항목을 누르면 완료 표시가 돼요)

1
구글시트 사본 만들기
참고자료 탭 아래 "사본 만들기" 버튼을 눌러 접속한 뒤, 화면에 뜨는 "사본 만들기" 버튼을 클릭해요. 원본은 그대로 두고 내 드라이브에 명렬표·제출데이터 시트와 코드가 통째로 복사돼요.
2
Apps Script 열기
복사된 구글시트 상단 메뉴에서 "확장 프로그램 → Apps Script"를 클릭해요.
3
웹 앱으로 배포
배포 → 새 배포 → 유형에서 "웹 앱" 선택 → 액세스 권한을 "모든 사용자"로 설정 → 배포를 눌러요. 처음 배포할 때 권한 승인 화면이 뜨면 모두 허용해주세요. 발급된 웹앱 URL을 복사해두면, 이 주소가 학생들이 접속할 홈 화면 주소가 돼요. (웹앱 URL은 나중에 배포 → 배포 관리에서 다시 확인할 수 있어요)
4
확인해보기 (기능 테스트)
발급된 웹앱 URL로 들어가서, 이 페이지 자가진단·수업으로의 확장 탭에서 안내한 예시 데이터(박보건 등)로 먼저 기능을 하나씩 눌러봐요.
5
명렬표 채우기
테스트가 끝나면 예시 데이터를 실제 학생 명단으로 교체해요. 학년·반·번호·이름만 입력하면 학번은 수식으로 자동 생성돼요.
6
관리자 비밀번호 설정
구글시트 상단 메뉴 "마음근육 관리 → 관리자 비밀번호 설정"에서 원하는 비밀번호를 새로 정해요.
7
다시 재확인해보기
실제 학생 이름으로 조회가 잘 되는지, 관리자 페이지에 새 비밀번호로 로그인되는지 최종 확인해요.
💡 코드를 수정한 뒤에는 저장만으로는 반영되지 않아요. 배포 → 배포 관리 → 새 버전으로 배포를 다시 눌러야 실제 주소에 반영돼요.
💡 실제 학생 명단을 넣기 전에, 구글시트에 남아있는 예시 데이터(박보건~최보건)는 지워주시는 걸 추천드려요.
